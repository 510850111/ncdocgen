## 系统概述

### 设计目标

ncdocgen 是一个C语言文档自动生成工具，设计目标包括：

- **自动化**: 从源代码自动提取注释生成文档
- **准确性**: 基于真实代码生成，确保文档与代码同步
- **可视化**: 自动生成流程图，直观展示代码逻辑
- **易用性**: 提供GUI界面，无需命令行知识

### 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 编程语言 | Python 3.10+ | 跨平台、丰富的库支持 |
| GUI框架 | tkinter | Python标准库，无需额外安装 |
| 词法/语法分析 | PLY (Python Lex-Yacc) | 类Unix工具的经典实现 |
| 打包工具 | PyInstaller | 将Python打包为单文件EXE |
| 流程图工具 | PlantUML | 文本转流程图的标准方案 |
| 符号提取 | universal-ctags | 业界标准的代码符号提取工具 |

## 模块说明

### 1. 入口层

#### gui.py
- **职责**: 提供图形用户界面
- **功能**:
  - 文件选择对话框
  - 参数配置界面
  - 实时日志显示
  - 后台任务管理（多线程）
- **设计要点**:
  - 使用 `threading` 避免GUI阻塞
  - 使用 `trace_add` 实现界面状态联动
  - 支持exe打包后的路径处理

#### cdocgen.py
- **职责**: 提供命令行界面
- **功能**:
  - 参数解析（Click库）
  - 批量处理支持
  - 简单的文本输出

### 2. 核心处理层

#### visio/cmarkdown.py
- **职责**: Markdown文档生成器
- **核心类**: `CMarddownDoc`
- **功能**:
  - 协调词法分析和语法分析
  - 生成函数说明表
  - 嵌入PlantUML流程图
  - 输出Markdown文件

#### visio/puml_drawer.py
- **职责**: PlantUML流程图绘制器
- **核心类**: `puml_drawer`
- **功能**:
  - 遍历语法树生成流程图
  - 支持多种控制结构（if/for/while/switch等）
  - 提取注释作为流程节点说明

### 3. 语言解析层

#### clang/clex.py
- **职责**: C语言词法分析器
- **核心类**: `clex`
- **功能**:
  - 使用PLY定义C语言词法规则
  - 提取 `/** */` 格式的流程图注释
  - 加载Key.txt进行关键字识别
  - 支持中文字符串和注释（UTF-8编码）

#### clang/cyacc.py
- **职责**: C语言语法分析器
- **核心函数**: `cyacc()`
- **功能**:
  - 使用PLY定义C语言语法规则
  - 构建抽象语法树（AST）
  - 错误恢复和静默处理

#### common/cgrammar.py
- **职责**: C语法处理
- **核心类**: `cgrammar`
- **功能**:
  - 合并连续节点
  - 搜索注释
  - 识别控制结构

### 4. 基础组件层

#### common/key_generator.py
- **职责**: Key.txt生成器
- **核心类**: `KeyGenerator`
- **功能**:
  - 调用ctags扫描项目
  - 分类提取符号（宏、结构体、枚举等）
  - 生成格式化的Key.txt

#### common/cglobal.py
- **职责**: 全局常量定义
- **内容**:
  - 节点索引常量（TV_ID, TV_X等）
  - 节点类型常量（DONEIF, DONEFOR等）
  - 辅助函数

#### visio/puml_url_generator.py
- **职责**: PlantUML URL生成
- **功能**:
  - 将PlantUML代码编码为URL
  - 支持在线图片嵌入

### 5. 外部工具层

#### ctags/
- **内容**: universal-ctags 可执行文件
- **用途**: 提取代码符号生成Key.txt
- **集成方式**: 通过subprocess调用

递归下降遍历AST：

```python
def print_func_exp(self, exp, x=0, y=0, in_loop=False, depth=10):
    ttype = get_type(exp)
    
    if ttype == 'DONENODE':
        # 普通语句节点
```

### 4. PlantUML编码算法

特殊的6bit编码方案：

```python
def puml_encode(data):
    # 1. Deflate压缩
    compressed = zlib.compress(data, 9)
    compressed = compressed[2:-4]  # 去掉zlib头尾
    
    # 2. 3字节分组编码为4字符
    result = []
    for i in range(0, len(compressed), 3):
        b1, b2, b3 = compressed[i:i+3]
        c1 = b1 >> 2
        c2 = ((b1 & 0x3) << 4) | (b2 >> 4)
        c3 = ((b2 & 0xF) << 2) | (b3 >> 6)
        c4 = b3 & 0x3F
        result.append(encode_6bit(c1) + encode_6bit(c2) + 
                     encode_6bit(c3) + encode_6bit(c4))
    
    return ''.join(result)
```

## 扩展性设计

### 1. 新增语言支持

要支持新的编程语言：

1. 在 `clang/` 下创建新的词法/语法分析器
2. 实现对应的语法树构建逻辑
3. 在 `cmarkdown.py` 中添加语言选择

### 2. 新增输出格式

要支持其他输出格式（如Word、PDF）：

1. 在 `visio/` 下创建新的输出器类
2. 实现与 `CMarddownDoc` 类似的接口
3. 在GUI中添加格式选择

### 3. 流程图样式定制

通过修改 `puml_drawer.py`：

- 添加新的节点类型处理
- 修改PlantUML主题设置
- 支持自定义样式模板
