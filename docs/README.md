## 快速开始

### 安装

1. 下载 `ncdocgen.exe`
2. 双击运行即可，无需安装

### 基本使用

1. 启动程序
2. 选择要分析的C源文件
3. 点击"➕生成Key"（首次使用）或"🔄更新Key"
4. 点击"🚀 开始生成文档"
5. 查看生成的 `output.md` 文件

更多详细说明请参阅 [用户手册](USER_GUIDE.md)。
